# Changjiang Han — personal homepage

Static site (no build step), hosted on GitHub Pages.

## Preview locally
    python3 -m http.server 8000
    # open http://localhost:8000

## Where to edit
| What | File |
|---|---|
| News, publications | `assets/js/data.js` |
| Bio, experience, philosophy, sidebar links | `index.html` |
| Colors, fonts, layout | `assets/css/style.css` (tokens at the top) |
| Photo | `assets/img/profile.jpg` |
| CV | put the PDF at `assets/cv.pdf` |
